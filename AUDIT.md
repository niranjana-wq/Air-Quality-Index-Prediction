## 3. Leakage Audit

### 3a. Interpolation (src/aqi_eda_model.py lines 193-203)

  grp[col].interpolate(method="linear", limit=3, limit_direction="forward")

Behaviour verified by execution:
  Series:  [nan, nan, 3.0, nan, 5.0]
  forward: [nan, nan, 3.0, 4.0, 5.0]   <- fills forward only (causal)

limit_direction="forward" fills only from the last known value forward.
NaNs at the series start remain NaN. No future-value leakage across the
train/test boundary.
VERDICT: PASS

### 3b. Winsorizing Thresholds (lines 241-246)

  lo = df[col].quantile(0.005)   # on ALL data (2015-2020)
  hi = df[col].quantile(0.995)   # on ALL data (2015-2020)
  df[col] = df[col].clip(lower=lo, upper=hi)

The clip thresholds use pollutant values from the test period (Oct 2019-Jun 2020)
to set limits applied to the training data. Soft leakage: ~1% of data per tail.
VERDICT: FAIL (soft)
Fix: compute quantiles on train rows only; apply same thresholds to val and test.

### 3c. Rolling Features and Lags (lines 727-745)

  grp[f"{col}_lag{lag}"] = grp[col].shift(lag)   # shift(1/2/3)
  shifted = grp[col].shift(1)                      # window ends D-1
  grp[f"{col}_roll7_mean"] = shifted.rolling(7, ...).mean()

Predicting D+1; features use up to D-1. Two-day gap. VERDICT: PASS

### 3d. Reindexed Calendar Rows (line 771)

Synthetic NaN rows created by reindex are dropped by dropna on FEAT_COLS + targets.
VERDICT: PASS

### 3e. StandardScaler (lines 822-826)

  scaler.fit_transform(X_tr)   # fit on train only
  scaler.transform(X_va)
  scaler.transform(X_te)

VERDICT: PASS

### 3f. City One-Hot Encoding

pd.get_dummies applied before split, but all 26 cities appear in all splits.
Column set would be identical if done per-split. No numeric leakage.
VERDICT: PASS (acceptable)

## 4. Distribution Shift

Split boundaries and AQI statistics (executed):

  Split  | Date range                | n rows | AQI mean | AQI std
  Train  | 2015-01-04 -> 2019-01-02  | 13,394 | 189.7    | 153.2
  Val    | 2019-01-03 -> 2019-10-01  |  5,058 | 147.0    | 133.1
  Test   | 2019-10-02 -> 2020-06-30  |  6,398 | 133.2    | 105.8

AQI mean drops monotonically train -> test. Model trained on historically
worse air quality, evaluated on cleaner periods.

COVID-19 in test set (Mar 24 - Jun 1, 2020):
  COVID rows     : 1,717 (26.8% of test), AQI mean = 87.7
  Non-COVID rows : 4,681 (73.2% of test), AQI mean = 149.9
  Train mean     : 189.7

26.8% of the test set is during COVID lockdown where AQI = 87.7 vs
train mean 189.7 (a 54% drop). This is a significant distribution shift
that must be discussed in the Limitations section.

VERDICT: PASS (numbers quantified)

AQI_Bucket distribution (full model dataset):

  Class          Count   Share
  Good            1,341   5.4%
  Satisfactory    8,224  33.1%
  Moderate        8,829  35.5%
  Poor            2,781  11.2%
  Very Poor       2,337   9.4%
  Severe          1,338   5.4%

Per-class precision/recall/F1 NOT saved in results.json.
Only mlp_f1=0.4738 (macro) and mlp_acc=0.5504 stored.

Why macro-F1 is low (0.47):
1. Class imbalance: Good and Severe are rare (5.4% each).
2. Ordinal adjacency: Moderate/Poor/Very Poor share AQI 101-300 with fuzzy
   boundaries; model confuses neighbouring buckets.
3. COVID distribution shift: test period has disproportionately many
   Good/Satisfactory days not seen in training.
4. No baseline comparison: majority-class baseline would give macro-F1 ~0.17;
   bucket-persistence baseline unreported.

VERDICT: FAIL
